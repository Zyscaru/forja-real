# Forja Real

Jogo de Java **avançado**. No Reino de Valdória você é o engenheiro da corte, e o conselho real julga cada peça de código comparando a saída com a do Java de verdade. São 18 missões em 6 distritos:

- **Oficina das Runas:** classes e métodos genéricos com limites, interfaces com métodos `default` e `static`, `Comparator` encadeado.
- **Salão dos Registros:** records com construtor compacto, enums com atributos e métodos, máquina de estados com `switch`.
- **Biblioteca de Pergaminhos:** streams, `Collectors` (`groupingBy`, `partitioningBy`, `joining`, `toMap`), `flatMap` e `Optional`.
- **Torre do Arquimago:** `Iterable` com classe anônima, padrão Builder com classe aninhada, padrão Observer com lambdas.
- **Masmorra:** interfaces seladas, pattern matching com guardas e desmontagem de records, exceções verificadas e try-with-resources.
- **Cidadela:** Dijkstra com `PriorityQueue`, ordenação topológica e busca em largura com estado em bitmask.

O Java roda direto no navegador e o jogo funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.
